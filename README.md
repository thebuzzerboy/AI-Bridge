# AI Bridge

Android AI client with a configurable OpenAI-compatible API endpoint.

## Current starter features
- Compose chat interface
- Configurable API base URL
- Model ID and API key fields
- OpenAI-compatible `/chat/completions` requests
- GitHub Actions cloud APK build

## Build APK
Open **Actions** → **Build AI Bridge APK** → **Run workflow**. Download the APK from the run's artifacts.

## Current limitations
This initial build is a chat client, not yet an autonomous device agent. Android tool execution, accessibility integrations, workflows, persistent settings, and agent planning will be added in later versions. API keys currently remain in memory for the session and should not be exposed in screenshots or logs.
